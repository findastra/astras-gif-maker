# Gif Giraffe

*A pet app by Astra.*

Gif Giraffe is a placeholder for a pet app that will make GIFs. Nothing works yet. Its pixel twin and nine mood frames are in `art/frames/gif-giraffe/`, and `icon.png` is the idle frame.

## How to run it

Open `index.html` in a browser. It shows a placeholder page only.
