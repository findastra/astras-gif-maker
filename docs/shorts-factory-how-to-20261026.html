Shorts Factory

A tool of Astra’s GIF Maker (Gif Giraffe). By Astra.

It turns a topic, or a script you wrote, into a 1080×1920 vertical video for TikTok, Reels or Shorts: narration, burned-in captions, slow Ken Burns motion on every picture and crossfades between them.

topic + preset→script, 5–8 slides→pictures →voice per slide→ffmpeg→MP4 with captions

Every stage can run for free on your PC. Paid AI services are used only when you choose them.

1. Set it up once (Windows)

It needs Python 3.10+ and ffmpeg. In PowerShell, from astras-gif-maker\shorts-factory:

.\run-shorts-factory-20261026.ps1 -Install check

-Install installs only what is missing, with winget (Python 3.12, Gyan.FFmpeg). Leave it off to just check. Running it again changes nothing. If PowerShell blocks the script: powershell -ExecutionPolicy Bypass -File .\run-shorts-factory-20261026.ps1 check.

2. Make the free sample

.\run-shorts-factory-20261026.ps1 -Sample

Renders examples\fuzzbois-dry-run.json with placeholder Fuzzboi blobs and Windows’ own voice, no internet, and opens the video. Videos go to %LOCALAPPDATA%\astras-pet-os\astras-gif-maker\shorts-factory\videos\ unless you pass --out.

3. Recipes

Fuzzbois TikTok from your own drawings (free)

.\run-shorts-factory-20261026.ps1 make --offline --preset fuzzbois `
  --script .\my-fuzzbois.json --images "$HOME\Pictures\Fuzzbois export"

Pictures are used in name order, one per slide (name them 01.png, 02.png…). A slide’s own "image" wins. Put each Fuzzboi’s 6-digit look code in the slide’s "hex" so placeholders and image prompts use its colour.

Mommy’s promo, script written by a model

$env:ANTHROPIC_API_KEY = "<API key with a spend limit>"
.\run-shorts-factory-20261026.ps1 script --topic "Mommy's Friday dance class" --preset mommys --out .\mommys.json
# read and edit mommys.json, then:
.\run-shorts-factory-20261026.ps1 make --script .\mommys.json --images .\vrchat-captures

VR clip from screenshots

.\run-shorts-factory-20261026.ps1 make --offline --preset vr-clips --script .\vr.json --images "$HOME\Pictures\VRChat\2026-10"

4. The script file

Plain JSON you can write by hand. 5 to 8 slides. Check one with validate my.json.

{
  "schema": "shorts-factory-script-v1",
  "title": "Meet the Fuzzbois",
  "preset": "fuzzbois",
  "slides": [
    { "narration": "Stop scrolling. This little guy is a Fuzzboi.",
      "image_prompt": "one round fuzzy Fuzzboi waving",
      "caption": "stop scrolling",     // optional: on-screen text if shorter than narration
      "image": "art/01.png",           // optional: relative to this file
      "motion": "zoom-in",             // optional: zoom-in zoom-out pan-left pan-right pan-up pan-down still
      "hex": "ff3ec8" }                // optional: a Fuzzboi's look code
  ]
}

(JSON has no comments; they are shown here only to explain the fields.)

6. Handy options

--crossfade 0.5seconds of fade between slides
--transition fadealso fadeblack, fadewhite, slideleft, slideup, circleopen, dissolve, smoothleft
--supersample 2smoother motion; 1 renders about twice as fast
--crf 23quality: 18 is sharper and bigger, 28 smaller
--no-captionsno burned-in text
--work <folder>keeps script.json, pictures, voices, captions.ass, filter-graph.txt and result.json

7. Limits

  • Tested on Linux with espeak-ng and placeholders. The Windows voice (sapi), Piper, the PowerShell script and the paid providers have not been run yet: no keys or Windows PC were available.
  • Default model names (claude-sonnet-5-5, gpt-4.1-mini, gpt-image-1, gpt-4o-mini-tts) were not checked against the live APIs; set the *_MODEL variables if one is refused.
  • No background music, no video clips as input (pictures only), one caption style per preset.
  • Captions use Arial Black or Arial; on a PC without them, libass picks a fallback font.
